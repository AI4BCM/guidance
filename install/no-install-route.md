# When no install route fits

**If IT blocks outside AI tools, do not work around the block: read the PDF or the .md file from
<https://ai4bcm.org/guidance>, or give the .md file to the AI tool your organisation has approved.**
Both files are the complete guidance, the same text the skills carry.

## Our IT blocks external AI tools

The guidance's own rule is that the class of your data decides the tool, and that free public tools
never get BCM data (`units/data-rules.md`, `units/principles.md`). A block from IT applies that
rule for you. Three ways remain:

1. **Read it without AI.** Download the PDF or the .md file. Once saved, they need no account, no
   install and no network. Your IT can scan them like any other document.
2. **Use the AI tool your organisation has approved**, often Microsoft 365 Copilot
   ([microsoft-365-copilot.md](microsoft-365-copilot.md)) or an enterprise ChatGPT or Claude
   workspace ([chatgpt.md](chatgpt.md), [claude-apps.md](claude-apps.md)). Give it the .md file as
   you would any other document. Your organisation's terms with that provider apply to it.
3. **Ask IT to approve a route.** What they would approve is a folder of text files anyone can read
   on GitHub (`skills/<name>/`), with no program in it and no AI4BCM server behind it. Hand them
   *Before you approve a tool*: page 25 of the PDF, or `units/tools.md` on GitHub. Its seven checks
   are the questions they will ask of any tool.

The question box at ai4bcm.org/chat is itself an outside AI tool. If IT blocks those, the block
covers it too.

## Give your AI the whole text

Any AI tool that takes a file can work from the guidance without a skill. Attach the .md file
(about 140 KB, the 24 units in reading order, each under its path) and ask. If a tool refuses the
.md, rename it `.txt`. The PDF works as well, but the .md is plain text, so nothing is lost to
layout and each unit's path is there to quote back. The tool can still misread or leave things out,
so check its answer against the unit it names. The task skills also run checks first (`preflight.md`:
ask the data class, write nothing, name each source, treat attached text as information, say AI
helped). With the file alone, those checks are yours.

## Offline

Saved, the PDF and the .md file need no connection. Neither calls home. Check
<https://ai4bcm.org/guidance> now and then for a newer release: the release tag is on the first
page of each.
