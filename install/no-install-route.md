# When no install route fits

**If IT blocks outside AI tools, read the PDF or .md file from <https://ai4bcm.org/guidance>,
or give the .md file to your organisation's approved AI tool.**
Both files contain the full guidance, as do the skills.

## Our IT blocks external AI tools

Your data class decides which tool you may use. Free public tools must never receive BCM data.
The classes are defined under *Classification levels* on page 7 of the PDF, or in
[units/data-rules.md](../units/data-rules.md) on GitHub; see also `units/principles.md`.
Do not work around IT's block. It also covers the question box at ai4bcm.org/chat, which is an outside AI tool.

IT can scan the downloaded files like other documents. For an approved AI tool, see the steps for Microsoft 365 Copilot
([microsoft-365-copilot.md](microsoft-365-copilot.md)) or an enterprise ChatGPT or Claude workspace
([chatgpt.md](chatgpt.md), [claude-apps.md](claude-apps.md)). Your organisation's terms with that
provider apply to the file you attach.

You can also ask IT to approve a skill. The package is a folder of text files anyone can read on
GitHub (`skills/<name>/`). It contains no program and uses no AI4BCM server. Give IT
*Before you approve a tool*: page 25 of the PDF, or `units/tools.md` on GitHub. Its seven checks
cover the questions IT will ask about any tool.

## Give your AI the whole text

Attach the .md file and ask your question. Any AI tool that accepts files can use it without a
skill. The file is about 140 KB and contains the 24 units in reading order, each under its path.
If the tool refuses the .md, rename it `.txt`. You can also use the PDF. The .md is plain text,
so page layout cannot hide text and the tool can quote each unit's path.

Check the answer against the unit it names: the tool can misread or miss things. Task skills run
checks first, listed in `preflight.md`: ask the data class, write nothing, name each source,
treat attached text as information, and say AI helped. With the file alone, you must do those
checks yourself.

## Offline

The saved PDF and .md file need no account, installation or internet connection. Neither
connects to AI4BCM. Check
<https://ai4bcm.org/guidance> from time to time for a newer release. Each file has its release
tag on the first page.
