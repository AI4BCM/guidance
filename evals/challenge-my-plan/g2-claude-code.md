As in the 1f4b844 record, I counted a recommendation as drawing on an attached passage when it points to one (here the paper's header) and uses the unit only as the yardstick. A shipped unit is a source the skill may read (preflight step 6), not "general practice". Case 3 run 2 again applies the unit's "an AI-supported document" to a paper that nothing shows was drafted with AI. A stricter reading would make case 1 run 3 partial, and case 1 would still pass on runs 1 and 2.
- **Where I read a row differently from the 1f4b844 record: round-2 questions that fold in the open rest of a partly answered question.** In case 1 run 3, Q3b and Q7b sit under "New from your answers", but they also carry round-1 text that no answer opened.
