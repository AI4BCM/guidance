**Method 1, weakened.** The unit's step 1 reads "Fix the sources you will attach, and their dates. With memory, past chats, project files, connectors and web search switched off, what you do not attach is not in the answer. Where any of them is on, the model may draw on it without saying so. Whether the model filled the gap or left it out, the output looks the same." The skill now reaches that condition, which is the fix since the last review: its step 1 asks the organiser whether memory, past chats, connectors or web search are on and files any that are on under Gaps with the unit's own reason. Two things still differ from the unit. The unit works from the off state — only with those channels off is what you did not attach out of the answer — and the skill never asks the manager to switch them off; it accepts a draft built with memory or a connector live, provided the fact is noted under Gaps. A noted draft is auditable but it is still a draft in which a requirement carried over from a past chat looks the same as one drawn from an attached register, which is the failure the unit's last sentence names. And the skill's list drops "project files" from the unit's five, so a project file loaded in the tool is the one channel the organiser is never asked about, in the skill whose whole task runs off attached project material. A line asking for those channels off before the draft, with the Gaps note as the fallback where the manager cannot turn one off, would carry the step. Everything else step 1 asks is carried: the Intake question set and the "own statements, not sources" filing follow `units/prompts/bia.md`.
