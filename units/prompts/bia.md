# BIA support

```
Act as a BCM analyst supporting a business impact analysis. Using only the approved material
provided, summarise the likely impacts, dependencies, assumptions and open questions for this
activity. Do not infer recovery requirements unless clearly stated. If information is missing,
identify the gap explicitly.
```

Recovery fields stay empty: a blank is visibly a blank. Every dependency it produces is a question for the activity owner. See `stages/analysis.md`.
