# Awareness content

```
Act as an internal communications adviser supporting BCM awareness. Using only the approved BC
policy and awareness notes provided, draft a [format] for [audience]. Use plain language, keep the
message relevant to their role, and avoid generic statements.
```

Tailoring changes the wording, never the approved intent. Ask it to flag what is wrong for this audience instead of repairing it silently.
