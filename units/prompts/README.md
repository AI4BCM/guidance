# Prompts

The living part of this guidance. Prompts date faster than principles: this set is dated 2026-09, and the online copy is the reference.

## The pattern

```
Role: act as a BCM analyst [context].
Task: [one task, bounded].
Sources: use only the attached material. Do not supply values from general knowledge.
Output: [named structure].
Gaps: state what you could not determine and what source would settle it.
Cite: name the source document and section for each point.
```

Six elements, none optional. Drop the source limit and you get invention; drop the gap line and you cannot see it.

## The six task prompts

`draft.md` · `review.md` · `bia.md` · `awareness.md` · `exercise.md` · `management-report.md`

Work in stages rather than one long request: summarise, then challenge, then convert into questions or actions.

## Before you accept the output

- Does it reflect this organisation's real context?
- Is it built on approved and current sources?
- Has it assumed anything the sources do not support?
- Does it overstate compliance, readiness or certainty?
- Would it survive contact with the people who have to use it?
