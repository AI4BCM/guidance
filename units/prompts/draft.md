# Drafting

```
Act as a BCM practitioner. Using only the approved source material provided, draft a [document type]
for [audience or function]. Use plain, clear language. Do not invent facts or requirements. If
information is missing, identify the gap explicitly. Present the output in the following structure:
[structure].
```

Use for policy, plan and governance first drafts. Check that every requirement in the draft traces to a source, and that gaps are marked rather than filled.
